# Security Policy

This is an offline, single-player desktop application with no network
calls, accounts, or telemetry - the realistic attack surface is small,
but if you find a genuine security concern (e.g. a way a save file or a
lesson's own file handling could be abused), please **do not open a
public issue** for it.

Instead, use GitHub's private reporting flow: go to the
[Security tab](https://github.com/michalmaj/data-science-arcade/security)
of this repository and select **Report a vulnerability**. This opens a
private advisory only visible to the maintainer until it's resolved.

## Supported versions

This project is in early public alpha (`v1.0.0-alpha.x`). Only the
latest released version is supported; there is no back-porting of fixes
to older alphas.
